# Work with the keyboard

Every page and ordinary action uses native buttons, inputs and links. Press Tab to move forward, Shift+Tab to move back, Enter/Space to activate a button, and arrow keys to change a select or checkbox as your browser normally supports. A visible green/gold outline shows focus. The first link skips navigation and takes you to the workspace.

## Bill without the mouse

1. F2 opens POS. F3 focuses search. Scan an exact barcode/SKU and press Enter to add one unit. Unknown barcodes do not create products.
2. Type a name, then Down to focus the product results. Arrows and Home/End choose a card; Enter/Space adds it. Enter on a unique name result adds it directly. Use Tab for customer, quantity, case, price tier and discount controls.
3. F8 opens checkout on Payment method. Choose the payment, Tab to the received amount or other fields, then Ctrl+Enter to save. Wait for the saved invoice before printing. UPI/card selection records payment; it does not charge a customer.
4. Tab to Print / Save PDF, then Enter. Your browser/Windows handles its print dialog. Escape closes the invoice; F9 searches history.

F2 never clears the current basket. Clear bill is a separate button. Repeated held Enter does not add repeated products or submit repeatedly. A form being saved stays open until a result arrives. Native required/minimum/pattern validation still applies.

## Forms, filters and tables

F4 starts the primary entry on inventory, purchases, café menu, profiles, reports, planning or owner staff/WhatsApp pages. Alternatively Ctrl+K finds an action such as Add customer or Transfer stock. Focus starts in the first editable field. Tab wraps inside dialogs; Escape returns to the opener. Read-only invoice/help dialogs start at their title.

Focus a view/category tab and use Left/Right or Home/End to activate another filter. Focus a product card and use arrows or Home/End to browse the grid. Tables are focusable regions so browser arrow scrolling can reveal columns. Background redraws retain the current input and selection.

On a small screen, hidden navigation is skipped during Tab traversal. Alt+N opens it and focuses its first page button; Escape closes it and returns to Menu. Ctrl+K remains available. On Mac, Command+K and Command+Enter work alongside the Control variants.

## Retire the deleted review connection

On an owner account, Alt+S opens Settings. Tab to Server permanently removed?, Enter, type RETIRED and Ctrl+Enter. The PC makes a local backup, removes the old address, pauses delivery and keeps all local records and pending changes. This cannot recover a bill held only on another PC or on the former server. Reconcile all copies and the saved server backup before starting folder exchange.
